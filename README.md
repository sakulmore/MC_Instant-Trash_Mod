# Minecraft (Fabric) - Instant Trash Mod
Instant Trash is a simple, highly efficient inventory management mod for Minecraft. It allows you to quickly and permanently delete unwanted items directly from any container or inventory screen. Say goodbye to tossing stacks of dirt on the ground, filling up chests with junk, or carrying around buckets of lava just to destroy trash!

# Requirements
- Fabric API

# Supported Minecraft Versions
| Version |
| - |
| 26.2 |
| 26.1.X |

# Usage
- First you need to set up your keyboard shortcuts in Key Binding in the classic game menu (settings).
- Then you can easily delete items from your inventory or chests with the bound keys.

# Multiplayer
**it must be installed on both the Client and the Server** to work in multiplayer environments.
